About Expense Tracker

Expense Tracker is a personal finance management application that helps users manage their daily income and expenses efficiently.


✨ Features

  • ✔ Add Income & Expenses
  • ✔ Dashboard with Balance Summary
  • ✔ Monthly Statistics
  • ✔ Category-wise Expense Chart
  • ✔ Transaction History
  • ✔ Search, Filter & Sort Transactions
  • ✔ Download Transactions as CSV
  • ✔ Dark / Light Mode

🛠 Technologies Used

  • HTML5
  • CSS3
  • JavaScript
  • Chart.js
  • Local Storage
